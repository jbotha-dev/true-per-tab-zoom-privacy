True Per-Tab Zoom — Privacy Policy

Last updated: 9 November 2026
Applies to: True Per-Tab Zoom for Microsoft Edge, version 1.0.4

Publisher and scope

True Per-Tab Zoom is an independently developed Microsoft Edge extension published as JBotha Labs. This policy applies to the extension version 1.0.3 and describes what the extension itself does. Microsoft Edge and the Microsoft Edge Add-ons website may process information under their own privacy policies.

Information used for zoom

When you open the extension popup, it asks Microsoft Edge for the active tab and uses its numeric tab identifier. It also reads the zoom factor for that tab. When you select a preset, it asks Edge to change the zoom setting for that tab only. These values are used temporarily to perform the requested action; the extension does not save or send them.

Permission and possible tab metadata

The extension requests the activeTab permission. When you invoke it, this permission can temporarily make details of the active page, including its URL and title, available to the extension. The current code does not inspect or use the page URL, title, favicon, webpage contents, typed text, or browsing history. It uses the tab identifier and zoom setting only. It does not inject scripts into webpages.

Collection, storage and transmission

The extension does not collect or transmit user data to the publisher or to external servers. It has no tracking, analytics, advertisements, cookies, user accounts, or external services. It does not save browsing records or zoom profiles. Errors, if any, are displayed in the popup and are not sent to the publisher. Edge may maintain normal browser settings independently of this extension.

Optional support correspondence

If you voluntarily contact the publisher through the support details provided on the Microsoft Edge Add-ons listing, your message may include your email address, name, and any information you choose to provide. This correspondence is separate from the extension: the extension does not send support messages automatically. The publisher uses support correspondence to respond to your request, does not sell it or use it for advertising, and may retain it only as reasonably necessary for support, recordkeeping, or applicable legal obligations. Email providers involved in delivering the message also process it according to their own policies.

Your choices and requests

You can choose any zoom preset, select 100% to return the active tab to normal zoom, or disable or uninstall the extension in edge://extensions/. The extension has no publisher-held browsing records to retrieve, correct or delete. If you have emailed the publisher for support, you can use the same published support contact to ask about, correct, or request deletion of that correspondence, subject to legal obligations.

Changes to this policy

If a future release changes the way the extension handles information, this policy and the corresponding Microsoft Edge Add-ons disclosures will be updated. The current policy is also included inside the extension.

Contact

For questions about this policy or support requests, use the public support contact in the publisher section of the Microsoft Edge Add-ons listing for True Per-Tab Zoom. The publisher provides a support contact through that listing.

True Per-Tab Zoom is not affiliated with or endorsed by Microsoft.
